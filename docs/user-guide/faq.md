# Frequently Asked Questions

## General Questions

### What is Notes MD?
Notes MD is a web application for creating and managing notes in Markdown format. It provides a clean interface with real-time preview capabilities.

### Is Notes MD free to use?
Yes, Notes MD is open source and free to use under the MIT License.

### What browsers are supported?
Notes MD works in all modern browsers including Chrome, Firefox, Safari, and Edge.

## Usage Questions

### How do I create a new note?
Click the '+' button in the top-left corner to create a new note.

### How do I set a note title?
Start your note with a heading using `# Your Title Here`. The title will be automatically extracted.

### Are my notes saved automatically?
Yes, notes are automatically saved as you type using your browser's local storage.

### Can I use Notes MD offline?
Currently, Notes MD works offline for existing notes but requires an internet connection for the initial load.

## Technical Questions

### Where are my notes stored?
Notes are currently stored in your browser's local storage. Future versions may include cloud storage options.

### Can I export my notes?
Export functionality is planned for future releases. Currently, you can copy the markdown content manually.

### Does Notes MD support collaborative editing?
Collaborative editing is not currently supported but is planned for future releases.

## Troubleshooting

### My notes aren't saving
Try refreshing the page. If the problem persists, check if your browser has local storage enabled.

### The preview isn't updating
Ensure you're using a supported browser and try refreshing the page.

### I can't see the '+' button
Check if your browser window is wide enough to display the full interface.
