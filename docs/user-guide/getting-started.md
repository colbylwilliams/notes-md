# Getting Started with Notes MD

## Welcome!

This guide will help you get up and running with Notes MD quickly.

## First Launch

When you first open Notes MD, you'll see:

- **Left Panel:** Note list (empty initially)
- **Center Panel:** Markdown editor
- **Right Panel:** Live preview of your markdown

## Creating Your First Note

1. **Click the '+' button** in the top-left corner
2. **Start typing** in the editor panel
3. **Use '# Title'** at the beginning of your note to set its title
4. **Watch the preview** update in real-time on the right panel

## Basic Workflow

### Writing Notes
- Type markdown in the left editor panel
- See the rendered result in the right preview panel
- Your note title is automatically extracted from the first line

### Managing Notes
- **Create:** Click the '+' button
- **Select:** Click any note in the left panel to edit it
- **Auto-save:** Changes are saved automatically as you type

## Essential Markdown

Here's a quick primer on the most commonly used markdown syntax:

```markdown
# Heading 1
## Heading 2
### Heading 3

**bold text**
*italic text*

- Bullet point 1
- Bullet point 2

1. Numbered list item 1
2. Numbered list item 2

[Link text](http://example.com)

`inline code`

```code block```
```

## Tips for New Users

- **Start with a heading:** Use `# My Note Title` at the beginning
- **Use the preview:** The right panel shows exactly how your note will look
- **Organize with headings:** Use `##` and `###` for sub-sections
- **Try different markdown:** Experiment with lists, links, and formatting
