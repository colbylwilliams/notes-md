## What is Notes MD?

Notes MD is a web application designed for taking and managing notes in Markdown format. It provides a clean, intuitive interface with real-time preview capabilities.

## Key Features

- **Real-time Preview:** See your markdown rendered as you type
- **Dark Mode:** Easy on the eyes for extended writing sessions  
- **Auto-save:** Never lose your work
- **Responsive Design:** Works on desktop, tablet, and mobile
- **Local Storage:** Your notes are stored locally in your browser
