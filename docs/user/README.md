## What is Notes MD?

Notes MD is a web application for taking and managing notes in Markdown format. It provides a clean, intuitive interface for writing and organizing your thoughts, documentation, and ideas.

## Key Features

- **Markdown Support**: Write notes in Markdown with real-time preview
- **Auto-save**: Your notes are automatically saved as you type
- **Dark Mode**: Toggle between light and dark themes
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Note Management**: Create, edit, delete, and organize your notes
