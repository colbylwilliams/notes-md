The Notes MD web application is a React-based frontend for creating and managing markdown notes.

### Key Features
- Real-time markdown preview
- Dark mode support
- Responsive design
- Local storage persistence
- Auto-save functionality (configurable)

### User Interface
- **Note List**: Browse and select notes
- **Editor**: Write markdown content
- **Preview**: Real-time rendered output
