# Notes MD Documentation

Welcome to the Notes MD documentation! This is a comprehensive guide for developers, contributors, and users of the Notes MD application.

## Overview

Notes MD is a web application for taking and managing notes in Markdown format. It consists of a React frontend and an Express backend API.
