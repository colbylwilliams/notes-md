# Notes MD Documentation

Welcome to the Notes MD documentation! This is a comprehensive guide for developers, contributors, and users of the Notes MD application.

## Overview

Notes MD is a web application for taking and managing notes in Markdown format, featuring real-time preview, dark mode support, and a REST API for programmatic access.
