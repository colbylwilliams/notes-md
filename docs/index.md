# Notes MD Documentation

Welcome to the Notes MD documentation! This is a comprehensive guide to understanding, using, and contributing to the Notes MD project.

## Overview

Notes MD is a web application for taking and managing notes in Markdown format. It consists of a React frontend and an Express.js API backend.

- [Frontend Documentation](./frontend/) - React application components and architecture

## Quick Start

For a quick start, see the main [README.md](../README.md) in the repository root.

## Architecture

### Frontend (`/web`)
- React with TypeScript
- Vite for build tooling
- Material UI for components
- Real-time markdown preview

### Backend (`/api`) 
- Express.js with TypeScript
- RESTful API design
- In-memory storage (can be extended to use databases)
