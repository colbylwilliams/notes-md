# Notes MD Documentation

Welcome to the Notes MD documentation! This is a comprehensive guide for using, developing, and contributing to the Notes MD project.

## Overview

Notes MD is a web application for taking and managing notes in Markdown format. It features a React frontend with real-time markdown preview and an Express REST API backend.
