# Installation Guide

This guide covers setting up the Notes MD development environment.

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Git

## Quick Start

```bash
# Clone the repository
git clone https://github.com/colbylwilliams/notes-md.git
cd notes-md

# Install and start the frontend
cd web
npm install
npm run dev

# In a new terminal, install and start the API
cd api
npm install
npm run dev
```
