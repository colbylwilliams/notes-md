# Getting Started

This guide will help you get up and running with Notes MD quickly.

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Git

## Installation

### Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/colbylwilliams/notes-md.git
   cd notes-md
   ```

2. Install and run the frontend:
   ```bash
   cd web
   npm install
   npm run dev
   ```

3. In a new terminal, install and run the API:
   ```bash
   cd api
   npm install
   npm run dev
   ```

4. Open your browser to `http://localhost:5173`
