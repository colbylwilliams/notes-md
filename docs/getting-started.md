# Getting Started

## Overview

Notes MD is a web application for taking and managing notes in Markdown format. This guide will help you get up and running quickly.

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- A modern web browser

## Quick Setup

### 1. Clone the Repository

```bash
git clone https://github.com/colbylwilliams/notes-md.git
cd notes-md
```

### 2. Install Dependencies

For the frontend:
```bash
cd web
npm install
```

For the API:
```bash
cd api
npm install
```

### 3. Start Development Servers

Start the API server:
```bash
cd api
npm run dev
```

Start the frontend:
```bash
cd web
npm run dev
```

### 4. Access the Application

- Frontend: http://localhost:5173
- API: http://localhost:3000
