# Getting Started

Welcome to Notes MD! This guide will help you get up and running quickly.

## What is Notes MD?

Notes MD is a web application that allows you to create, edit, and manage notes written in Markdown format. It features:

- Real-time markdown preview
- Dark mode support
- Local storage persistence
- REST API for programmatic access
- Responsive design
