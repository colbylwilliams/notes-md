# Getting Started

This guide will help you get started with Notes MD.

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## Installation

For detailed installation instructions, please refer to the main [README.md](../README.md) in the root directory.

## Quick Start

1. Clone the repository
2. Install dependencies for both frontend and backend
3. Configure environment variables
4. Start the development servers
