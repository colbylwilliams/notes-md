# Getting Started with Notes MD

This guide will help you get up and running with Notes MD quickly.

## Overview

Notes MD is a web application for creating, editing, and managing notes written in Markdown format. It features a real-time preview, automatic title extraction, and a clean, responsive interface.

### For Developers

If you want to run Notes MD locally or contribute to development, please refer to the main [README.md](../README.md) for detailed installation instructions.

#### Quick Development Setup

1. **Prerequisites**: Node.js (v14 or higher), npm or yarn
2. **Clone**: `git clone https://github.com/colbylwilliams/notes-md.git`
3. **Install dependencies**: See main README for detailed steps
4. **Start development**: Run both frontend and API servers
5. **Access**: Open `http://localhost:5173` in your browser

For complete development setup instructions, see the [Development Guide](development.md).
