# Getting Started

## Overview

This guide will help you get Notes MD up and running on your local development environment.

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Git

## Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/colbylwilliams/notes-md.git
cd notes-md
```

### 2. Install Dependencies

```bash
# Install frontend dependencies
cd web
npm install

# Install backend dependencies
cd ../api
npm install
```

### 3. Start Development Servers

```bash
# Start the frontend (in web directory)
npm run dev

# Start the backend (in api directory)
npm run dev
```
