# Getting Started with Notes MD

This guide will help you get Notes MD up and running quickly.

## Overview

Notes MD is a full-stack application consisting of:
- **Frontend**: React application with TypeScript and Material UI
- **Backend**: Express.js REST API with TypeScript

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Git

## Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/colbylwilliams/notes-md.git
cd notes-md
```

### 2. Setup Frontend

```bash
cd web
npm install
npm run dev
```

The frontend will be available at `http://localhost:5173`

### 3. Setup API (Optional)

```bash
cd ../api
npm install
npm run dev
```

The API will be available at `http://localhost:3000`
