# User Guides

This directory contains step-by-step guides for using Notes MD.

## Getting Started Guide

### Installation and Setup

1. **Prerequisites**
   - Node.js (v14 or higher)
   - npm or yarn

2. **Installation Steps**
   - See [Getting Started](../README.md#getting-started) in the main README

### Your First Note

1. **Creating a Note**
   - Click the '+' button in the notes list
   - A new untitled note will be created and selected

2. **Writing Content**
   - Use the left editor panel to write markdown
   - See the rendered output in the right preview panel
   - The note title is automatically extracted from the first heading

3. **Saving Changes**
   - Changes are automatically saved as you type
   - No manual save action required

### Managing Notes

1. **Selecting Notes**
   - Click on any note in the left sidebar to select it
   - The selected note will open in the editor

2. **Deleting Notes**
   - Click the delete icon (trash can) next to any note
   - Confirm the deletion when prompted

## Markdown Guide

```markdown
# Heading 1
## Heading 2

**Bold text**
*Italic text*
~~Strikethrough~~

- Bullet point
- Another bullet point

1. Numbered list
2. Another item

[Link text](https://example.com)

![Image alt text](image-url.jpg)
```
