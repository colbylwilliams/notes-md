# API Documentation

This section contains comprehensive documentation for the Notes MD REST API.

## Overview

The Notes MD API provides a RESTful interface for managing markdown notes. It supports full CRUD operations and is built with Express.js and TypeScript.

**Base URL:** `http://localhost:3000` (development)
