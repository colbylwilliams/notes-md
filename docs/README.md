## Documentation Standards

When creating documentation, please follow these guidelines:

- Use clear, concise language
- Include code examples where appropriate
- Add screenshots for UI-related documentation
- Keep documentation up-to-date with code changes
- Use consistent formatting and structure
- Include cross-references between related documents

## Getting Help

If you need help with documentation or have questions about any aspect of the Notes MD project:

- Check the existing documentation in this directory
- Review the main [README.md](../README.md) in the project root
- Open an issue on GitHub for documentation requests or improvements
- Refer to the individual component README files in `/web` and `/api` directories
