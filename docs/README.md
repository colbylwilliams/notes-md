# Notes MD Documentation

Welcome to the Notes MD documentation! This directory contains comprehensive guides and documentation for the Notes MD application.

## Documentation Overview

Notes MD is a full-stack web application for creating and managing markdown notes with real-time preview capabilities.

## About Notes MD

Notes MD is built with modern web technologies including:

- **Frontend**: React, TypeScript, Vite, Material UI
- **Backend**: Express.js, TypeScript, Node.js
- **Features**: Real-time markdown preview, dark mode, local storage, REST API
