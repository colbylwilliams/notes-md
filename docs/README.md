## 📝 About Notes MD

Notes MD is a modern web application for creating, editing, and managing notes in Markdown format. It features a clean interface with real-time preview, dark mode support, and a REST API for programmatic access.

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Vite, Material UI
- **Backend**: Express, TypeScript, Node.js
- **Markdown**: React Markdown, unified ecosystem
