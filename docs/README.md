# Notes MD Documentation

This directory contains the documentation for the Notes MD project.

## Documentation Structure

- `README.md` - This file, provides an overview of the documentation
- `getting-started.md` - Quick start guide for new users
- `api.md` - API documentation and reference
- `frontend.md` - Frontend application documentation
- `deployment.md` - Deployment and production setup guide
- `contributing.md` - Guidelines for contributing to the project

## About Notes MD

Notes MD is a web application for taking and managing notes in Markdown format, featuring:
- Real-time markdown preview
- Dark mode support
- Local storage persistence
- REST API for note management

For basic usage instructions, see the main [README.md](../README.md) in the project root.
