## 📝 About Notes MD

Notes MD is a web application for taking and managing notes in Markdown format, featuring:

- Real-time markdown preview
- Dark mode support
- Local storage persistence
- REST API backend
- Responsive design

## 🏗️ Architecture

The application consists of two main components:

- **Frontend** (`/web`) - React + TypeScript + Vite application
- **Backend** (`/api`) - Express + TypeScript REST API
