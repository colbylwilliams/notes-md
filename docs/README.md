## About Notes MD

Notes MD is a web application for taking and managing notes in Markdown format, featuring:

- Real-time markdown editing and preview
- Dark mode support
- Local storage persistence
- REST API for programmatic access
- Responsive design

For basic setup and usage, see the [main README](../README.md).
