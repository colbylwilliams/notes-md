## Overview

Notes MD is a web application for taking and managing notes in Markdown format. It consists of:

- **Frontend**: React + TypeScript + Vite application with Material UI
- **Backend**: Express.js REST API with TypeScript
- **Features**: Real-time markdown preview, dark mode, local storage, responsive design

For quick start instructions, see the [main README](../README.md). For detailed documentation, explore the guides linked above.
