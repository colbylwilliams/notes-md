## 📝 Project Overview

Notes MD is a modern web application that allows users to:
- Create, edit, and delete markdown notes
- See real-time markdown preview
- Organize notes with automatic title extraction
- Use dark mode for better viewing experience
- Access notes via REST API

### Tech Stack
- **Frontend**: React, TypeScript, Vite, Material UI
- **Backend**: Express, TypeScript
- **Storage**: Local storage (frontend), in-memory (backend)
