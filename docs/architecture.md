## Overview

Notes MD is a full-stack application for taking and managing notes in Markdown format.

### Tech Stack

- **Frontend**: React, TypeScript, Vite, Material UI, React Markdown
- **Backend**: Express (REST API), TypeScript

### Project Structure

- `/web` - Frontend application (React, TypeScript, Vite)
- `/api` - Backend REST API (Express, TypeScript)
