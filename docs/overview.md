## Project Architecture

Notes MD is a full-stack web application for taking and managing notes in Markdown format. The application consists of:

- **Frontend**: React-based web application with TypeScript
- **Backend**: Express.js REST API with TypeScript

### Technology Stack

- **Frontend**:
  - React 18
  - TypeScript
  - Vite (build tool)
  - Material UI (component library)
  - React Markdown (markdown rendering)

- **Backend**:
  - Node.js
  - Express.js
  - TypeScript
  - UUID (for note IDs)

### Key Features

- Create, edit, and delete markdown notes
- Real-time markdown preview
- Automatic note title extraction from content
- Dark mode support
- Local storage for persistence
- Responsive design
- REST API for note management
