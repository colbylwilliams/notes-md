# Installation & Setup Guide

This guide provides detailed instructions for installing and setting up the Notes MD application.

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Git

## Full Installation

### 1. Clone the Repository

```bash
git clone https://github.com/colbylwilliams/notes-md.git
cd notes-md
```

### 2. Frontend Setup

```bash
cd web
npm install
```

#### Environment Configuration

Create a `.env` file in the web directory:

```bash
cp .env.example .env
```
