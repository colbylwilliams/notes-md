# User Guide

Learn how to use the Notes MD application to create, edit, and manage your markdown notes.

## Getting Started

Once you have the application running (see [Getting Started Guide](getting-started.md)), you can access it at `http://localhost:5173`.

## Creating Your First Note

1. Click the **'+'** button to create a new note
2. Start typing your content in the editor
3. Use `# Title` at the beginning to set your note title
4. Your note is automatically saved as you type

## Writing in Markdown

Notes MD supports full Markdown syntax. Here are some examples:

### Headers
```markdown
# Main Title
## Subtitle
### Section Header
```

### Text Formatting
```markdown
**Bold text**
*Italic text*
`Code text`
```

### Lists
```markdown
- Bullet point 1
- Bullet point 2

1. Numbered item 1
2. Numbered item 2
```

### Links and Images
```markdown
[Link text](https://example.com)
![Image alt text](image-url.jpg)
```
