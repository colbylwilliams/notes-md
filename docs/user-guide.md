## Creating Your First Note

1. Open Notes MD in your browser
2. Click the '+' button to create a new note
3. Start typing your markdown content
4. See the live preview on the right panel

## Working with Notes

### Writing Markdown

Notes MD supports standard Markdown syntax:

- Headers: `# Title`, `## Subtitle`, `### Section`
- Bold: `**bold text**`
- Italic: `*italic text*`
- Lists: Use `-` or `1.` for lists
- Links: `[text](url)`
- Code: `` `inline code` `` or triple backticks for blocks

### Note Titles

The first line of your note (if it starts with `#`) becomes the note title automatically.

Example:
```markdown
# My Important Note

This is the content of my note.
```

### Editing Notes

- Select any note from the sidebar to edit it
- Changes are saved automatically as you type
- Use the preview panel to see how your markdown will render

### Managing Notes

- Create new notes with the '+' button
- Delete notes using the delete button in the note list
- Notes are stored locally in your browser
