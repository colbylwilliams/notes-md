# User Guide

## Introduction

Welcome to Notes MD! This guide will help you get started with using the application to create, edit, and manage your markdown notes.

## Features

Notes MD provides the following features:

- **Create Notes**: Easily create new markdown notes
- **Real-time Preview**: See your formatted markdown as you type
- **Edit Notes**: Modify existing notes with a user-friendly editor
- **Delete Notes**: Remove notes you no longer need
- **Dark Mode**: Toggle between light and dark themes
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## Getting Started

### Creating Your First Note

1. Click the "+" button to create a new note
2. Start typing in the editor on the left side
3. Use markdown syntax to format your content
4. See the live preview on the right side

### Note Title

The title of your note is automatically extracted from the first line of your content:
- Use `# Title` at the beginning to set the note title
- If no title is provided, it will be labeled as "Untitled Note"
