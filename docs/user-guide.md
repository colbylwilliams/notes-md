# User Guide

Complete guide for using the Notes MD application.

## Getting Started

Notes MD is a web-based markdown note-taking application that allows you to create, edit, and organize your notes with real-time preview.

### Accessing the Application

1. Open your web browser
2. Navigate to the application URL
3. Start creating notes immediately

## Features Overview

### Creating Notes

- Click the '+' button to create a new note
- Start typing in the editor pane
- Your note will be automatically saved

### Editing Notes

- Select any note from the list on the left
- Edit the content in the center editor pane
- See real-time markdown preview on the right

### Organizing Notes

- Notes are automatically titled based on the first heading (`# Title`)
- Notes are ordered by creation/modification date

### Dark Mode

- Toggle dark mode using the switch in the top toolbar
- Your preference is remembered between sessions

## Markdown Syntax

Notes MD supports standard markdown syntax:

```markdown
# Heading 1
## Heading 2
### Heading 3

*italic text*
**bold text**

- Bullet point
1. Numbered list

[Link](https://example.com)
![Image](image-url)
```
