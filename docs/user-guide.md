# User Guide

Welcome to Notes MD! This guide will help you get started with creating and managing your markdown notes.

## Overview

Notes MD is a web application that allows you to create, edit, and manage notes written in Markdown format. It features real-time preview, dark mode support, and a clean, intuitive interface.

## Getting Started

### Accessing the Application

1. Open your web browser
2. Navigate to the Notes MD application URL
3. The application will load with an empty note list

### Creating Your First Note

1. Click the '+' button to create a new note
2. Start typing your content in the editor panel
3. Use '# Title' at the beginning to set your note title
4. See the rendered preview in real-time on the right panel

## Features

### Markdown Support

Notes MD supports standard Markdown syntax including:

- **Headers** (`# H1`, `## H2`, etc.)
- **Bold** (`**bold**`) and *italic* (`*italic*`) text
- **Lists** (both numbered and bullet points)
- **Links** (`[text](url)`)
- **Code blocks** (`` `code` `` and ``` blocks)
- **Images** (`![alt](url)`)

### Interface Features

- **Real-time Preview**: See your formatted content as you type
- **Dark Mode**: Toggle between light and dark themes
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Auto-save**: Your changes are automatically saved (if enabled)
